another machine

At some point we forgot how simple the web can be.

Too often we find ourselves failing captchas and rejecting cookie policies...

...as the shape of the web spoils into something it never had to be.

Many experiences and tools you find today on the internet are an abrasive expression of the web.

We make things with an expressive web in mind.

Our tools are distributed via the Another Machine Public Library.

...or amplib for short.
